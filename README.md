# The WIP Meetup

Live site: [thewipmeetup.com](https://thewipmeetup.com)

Weekly web3 metaverse meetup, running since 2019. Everyone is welcome. Thursdays, 12 PM PT on Hyperfy.

This GitHub repo is a name stub so the project is findable. The site source lives in:

**[github.com/rizzlenft/wip-archive-hub](https://github.com/rizzlenft/wip-archive-hub)**

That repo is what deploys to thewipmeetup.com (episode archive, events, newsletter, check-in).
